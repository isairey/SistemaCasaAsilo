# 🏡 Sistema de Gestión para Casa Asilo

Plataforma web diseñada para la **administración y cuidado de adultos mayores** en una casa asilo, permitiendo gestionar residentes, personal y servicios de manera eficiente.

---

## 🚀 Descripción

El **Sistema de Gestión para Casa Asilo** es una aplicación web que facilita el control y seguimiento de los residentes, mejorando la organización interna y la calidad de atención.

La plataforma centraliza información importante como datos médicos, actividades, historial y monitoreo diario.

---

## 🎯 Objetivos

- Mejorar la gestión administrativa del asilo  
- Facilitar el seguimiento de residentes  
- Optimizar la atención y cuidados  
- Centralizar la información en un solo sistema  

---

## ✨ Características

### 👴 Gestión de Residentes
- Registro de residentes  
- Información personal y médica  
- Historial de atención  

### 🧑‍⚕️ Gestión de Personal
- Registro de cuidadores  
- Asignación de responsabilidades  
- Control de turnos  

### 💊 Control de Medicación
- Registro de medicamentos  
- Horarios de administración  
- Seguimiento de tratamientos  

### 📅 Actividades
- Programación de actividades diarias  
- Registro de participación  

### 📊 Reportes
- Estado de residentes  
- Historial de atención  
- Reportes administrativos  

---

## 🧱 Tecnologías utilizadas

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** (opcional) PHP / Node.js / Laravel  
- **Base de datos:** MySQL
